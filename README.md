# Cplusplus-Program
A C++ console application that reads a daily grocery purchase log, counts how often each item was purchased, and displays the results in multiple formats. Built for CS-210 at Southern New Hampshire University. Automatically creates `frequency.dat` backup on startup. Case-insensitive search so `apple`, `APPLE`, or `Apples` and it will still find the item.

---

## Files
- `CornerGrocer.cpp` — main source code
- `CS210_Project_Three_Input_File.txt` — daily purchase log (input)
- `frequency.dat` — auto-generated backup file (output)
